## Описание программ

В данном репозитории представлены следующие проекты:

- **Pass igra** — генератор псевдослучайных данных. Идея вдохновлена форматами интерактивных онлайн-трансляций.
- **oskorbi** — консольный посредник между пользователем и API (OpenRouter). Программа задает системный промпт и управляет диалогом с языковой моделью.
- **add_hour** — удобный калькулятор времени. Позволяет быстро рассчитать, сколько времени пройдет спустя заданное количество часов и минут, избавляя от ручных подсчетов "в уме".
- **nuclear** — интерактивный симулятор запуска с изменением паролей и генерацией псевдоданных в стиле интерфейсов управления.

---

## Важные примечания

> [!WARNING]
> Для работы программы `oskorbi` необходим действительный API-ключ OpenRouter. Его нужно будет получить самостоятельно и указать в коде.

> [!WARNING]
> **Ограничения:** Сервис OpenRouter может блокировать запросы из России. Для корректной работы API-запросов настоятельно рекомендуется использовать VPN.

## Стек технологий

- **Python 3.x** — основной язык программирования
- **OpenRouter API** — интеграция с языковыми моделями (LLM)
- **Python Standard Library** — использование встроенных модулей (random, time, os и др.)

## Установка и запуск

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Kievsky332/programs_of_python.git
   ```
2. Перейдите в папку проекта:
    ```bash
    cd programs_of_python
    ```
3. Установите зависимости
    ```bash
    pip install -r requirements.txt
    ```

4. Выберите проект.
    ```bash
      cd (add_hours ИЛИ nuclear ИЛИ oskorbi ИЛИ pass_igra)
    ```
5. Запустите выбранные проект
    ```bash
      python3 index.py
    ```
